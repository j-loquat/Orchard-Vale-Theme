# Orchard Vale Research Report Kit

Use this kit to turn research notes or a draft into a styled HTML report. The template includes the owl header, section navigation, evidence callouts, comparison table, confidence cards, source list, and print view from the Scholar’s Field Report demo. The files are local, so the report opens directly in a browser.

## Create a report with an AI assistant

1. Extract the ZIP and keep its folder structure.
2. Open [the example report](report/example.html) in your browser to see the completed layout.
3. Give your coding assistant access to the extracted folder and the notes or draft you want formatted. Ask it to read [AGENTS.md](AGENTS.md) and use [the editable template](report/template.html).

   > Read AGENTS.md. Turn my notes into an Orchard Vale HTML research report using report/template.html. Save it as report/my-report.html. Keep the layout and working controls, use the sources I provide, and flag gaps in the evidence.

4. Open the finished report in a browser. Check the section links, **Copy citation** buttons, and **Print / Export PDF**.

To edit by hand, duplicate `report/template.html` in the `report/` folder and replace the bracketed fields. Use the example report to see how the sections work together.

## Share or reuse the format

- Share the folder with the finished HTML, its two report files, and `src/` so the styling and controls travel with it. For a fixed copy, open **Print / Export PDF** and select your browser’s PDF destination.
- For a reusable skill, point the skill to this folder and tell it when to use the report template. Use [AGENTS.md](AGENTS.md) as the instructions for formatting and verifying reports.
