# Art Sources

Raw chroma-key generations and original renders archived out of the runtime asset tree (src/assets/orchard-vale/). Layout: art-sources/<family>/<source-keyed|source-originals>/. Not referenced by demos or the theme.

## Daylight map refresh

The Village Overview, Stables, and Market source PNGs were generated with the built-in ImageGen tool. Each prompt used the previous map as a layout reference, the original dashboard illustration for color and linework, and the Watermill district for architectural detail. The new masters have a `-daylight-source.png` suffix. The web maps use 1600 × 900 WebP derivatives.
