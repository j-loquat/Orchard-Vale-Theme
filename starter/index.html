    Lightweight Adoption Snippet

    Copy src/theme/ and the ~400 KB WebP texture core from src/assets/orchard-vale/textures/, then include two tags in your page head:

    <link rel="stylesheet" href="src/theme/index.css">
<script src="src/theme/orchard-vale.js" defer></script>

    Embedding inside an existing app? Put class="ov-theme" on any wrapper <div> instead of <body>; all rules live inside @layer ov.*.
