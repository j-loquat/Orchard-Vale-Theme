Start a page with Orchard Vale

Build a new HTML page or apply the theme to part of an existing site. You can run the starter directly in a browser with the theme files on disk.

Set up a new page

  1. Copy the theme folders

    From the kit, copy src/theme/ and src/assets/orchard-vale/ into your project. Keep these folder paths so the stylesheet can find its textures and artwork.

    your-project/
  index.html
  src/
    theme/
    assets/
      orchard-vale/

    Get the theme files on GitHub

  2. Create index.html

    Save the full starter HTML as index.html next to the src folder. It includes the stylesheet, a themed panel, and a button that opens a dialog.

    View starter HTML 
    <!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>My Orchard Vale page</title>
  <link rel="stylesheet" href="src/theme/index.css">
  <script src="src/theme/orchard-vale.js" defer></script>
</head>
<body class="ov-theme">
  <div class="ov-page">
    <main class="ov-shell ov-frame">
      <section class="ov-panel ov-panel--ornate" aria-labelledby="page-title">
        <h1 class="ov-panel-title" id="page-title">My Orchard Vale page</h1>
        <div class="ov-panel__body">
          <p>Replace this text with your content.</p>
          <button class="ov-button" type="button" data-ov-dialog-open="example-dialog">Test the dialog</button>
        </div>
      </section>
    </main>
  </div>
  <dialog class="ov-dialog" id="example-dialog" aria-labelledby="example-title">
    <header class="ov-dialog__header">
      <h2 id="example-title">Orchard Vale is working</h2>
      <button class="ov-dialog__close" type="button" data-ov-dialog-close aria-label="Close dialog">&times;</button>
    </header>
    <p class="ov-dialog__body">The theme stylesheet and JavaScript helper both loaded.</p>
  </dialog>
</body>
</html>

  3. Open and check the page

    Open index.html in a browser. Look for a parchment panel on a dark wood background. Select Test the dialog, then press Esc to close it.

    If the page looks unstyled, check that index.html sits next to src. If the dialog stays closed, check the path to orchard-vale.js.

To build out the page, start with a component example or inspect the source of a showcase demo.

Theme an existing page

  1. Copy the theme folders using the folder layout above.

  2. Add the stylesheet link to your page’s <head>. These paths assume the HTML file sits next to src. For an HTML file one folder deeper, prefix each path with ../.

    <link rel="stylesheet" href="src/theme/index.css">

  3. Add class="ov-theme" to <body> for the full page, or to a wrapper around the section you want to theme. Add ov-panel to a container inside that section to give it a parchment surface.

If you use the kit’s tabs, dialogs, or copy buttons, load the JavaScript helper in <head> as well.

<script src="src/theme/orchard-vale.js" defer></script>

Open the page on desktop and mobile. Check that the target section uses the theme and that the existing controls still work.
