# Orchard Vale Starter

Open `index.html` directly or copy the folder structure into a static HTML project.

The starter imports the three reusable theme layers:

1. `src/theme/orchard-vale.css` - tokens, typography, focus, motion, and base behavior.
2. `src/theme/orchard-components.css` - panels, ribbons, controls, chips, tables, callouts, and content patterns.
3. `src/theme/orchard-layouts.css` - responsive app, report, dashboard, finance, and starter layouts.

Keep the `src/assets/orchard-vale` folder at the same relative path or update the CSS asset URLs when moving the theme.
